## 🏥 Project Overview

SPINEVISION-AI enables doctors and healthcare professionals to upload spine X-ray images and receive instant AI-powered analysis, including:

- **Multi-Condition Detection** — Identifies Disc Space Narrowing, Osteophytes, Surgical Implants, and Normal findings
- **Dual-Model Architecture** — DenseNet-121 for whole-image classification + YOLOv9 for region-level localization
- **AI-Generated Heatmaps** — Visual overlays highlighting detected abnormal regions
- **Gemini-Powered Recommendations** — Expert-level clinical summaries generated by Google Gemini AI
- **Downloadable PDF Reports** — Professional diagnostic reports ready for clinical use
- **Doctor Approval System** — Admin-verified registration for medical professionals
- **Grayscale Validation** — Frontend canvas-based check rejects non-X-ray images before upload

## 🧠 AI Models

| Model | Architecture | Purpose | Classes |
|-------|-------------|---------|---------|
| **Classifier** | DenseNet-121 | Whole-image classification | Normal, Disc Space Narrowing, Osteophytes, Surgical Implant |
| **Detector** | YOLOv9c | Region-level localization | Osteophytes, Disc Space Narrowing, Surgical Implant |
| **Recommender** | Gemini 2.0 Flash | Clinical recommendation generation | N/A (text output) |

### Inference Pipeline

1. X-ray uploaded → sent to HuggingFace Space via REST API
2. DenseNet-121 classifies the entire image into 4 categories
3. YOLOv9 detects and localizes abnormal regions with bounding boxes
4. Heatmap is generated by blending bounding-box confidence with the original image
5. All predictions returned to backend
6. Gemini AI generates a clinical summary + recommendations based on findings
7. PDF report is generated with all results
8. Everything stored in PostgreSQL and served to the frontend

## 🚀 Quick Start (Local Development)

### Prerequisites
- Python 3.9+
- Node.js 18+
- PostgreSQL (or use SQLite for local dev)

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt

# Create .env file
echo DATABASE_URL=sqlite:///./spinevision.db > .env
echo SECRET_KEY=your-secret-key >> .env
echo GEMINI_API_KEY=your-gemini-key >> .env
echo HF_SPACE_URL=https://ziaur390-spinevision-ml-api.hf.space >> .env

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 📡 API Endpoints

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/register` | Register (requires admin approval) |
| POST | `/auth/login` | Login → JWT token |
| GET | `/auth/me` | Current user info |

### Analysis
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/upload` | Upload X-ray → full AI analysis |
| GET | `/result/{upload_id}` | Get results + recommendation |
| GET | `/result/{upload_id}/heatmap` | Download heatmap image |
| GET | `/result/{upload_id}/report` | Download PDF report |

### History & Admin
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/history` | Paginated upload history |
| GET | `/history/statistics` | Dashboard stats |
| DELETE | `/history/{upload_id}` | Delete a scan |
| GET | `/admin/pending` | List pending doctor accounts |
| POST | `/admin/approve/{user_id}` | Approve a doctor |
| POST | `/admin/reject/{user_id}` | Reject a doctor |
